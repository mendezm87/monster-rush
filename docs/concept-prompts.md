# Concept art prompts (90s / early-2000s cel anime)

For picking the redesigns of Sparkit, Cinderox and Lumawool. Paste a prompt into an image generator
(ChatGPT, Midjourney, Gemini...), keep the ones you like, and send them back: the chosen design then
becomes the monster's pixel sprite in the game.

**How to use:** each prompt below already includes the style. If an image comes out too cute, add
"fierce, battle-ready" to the end; too realistic, add "flat cel colours, no rendering". If a result
looks like a monster from another game, say so and try again: the point of the redesigns is that
they are original.

The shared style, already in every prompt:

> 1990s TV anime cel art, hand-inked line art with varying line weight, flat cel colours with one
> hard-edged shadow tone, soft airbrushed highlights, hand-painted watercolour background, slight
> film grain, 4:3 screenshot framing, original creature design, no text
